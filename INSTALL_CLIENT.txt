World of Tanks 0.8.2 experimental native bot physics
=====================================================

This package does not contain the game client. It supports only the verified
Windows 0.8.2 executable listed in START_NATIVE_TEST_HERE.txt.


Install the client files
------------------------

1. Close World of Tanks.
2. Open the game folder, then open res_mods.
3. Delete or move aside the complete old res_mods\0.8.2 folder.
4. Copy this package's complete 0.8.2 folder into res_mods.

The final entry file must be:

    <game folder>\res_mods\0.8.2\scripts\client\gui\mods\mod_offhangar.py

Do not merge individual files into an old 0.8.2 folder. The existing
<game folder>\offhangar_user folder is outside res_mods and remains intact, so
LAN settings and the nickname survive this complete replacement.


Run offline
-----------

No external server is required. Select a tank, click Battle!, and read
START_NATIVE_TEST_HERE.txt before evaluating movement or performance.


Run over LAN
------------

Replace the client folder on every PC. Run the server from this same package;
older build-1.8.26 servers deliberately reject this experimental client.
Only the authority client creates native bot rigid bodies. Replica clients keep
the existing snapshot and smoothing path.


Rollback
--------

Close the game and completely replace res_mods\0.8.2 with the previous stable
package. Do not merge the two trees. The offhangar_user settings remain intact.
