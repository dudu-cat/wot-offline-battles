WORLD OF TANKS 0.8.2 NATIVE BOT PHYSICS EXPERIMENT 1.8.36
==========================================================

This is a separate experimental build. It keeps the retail 0.8.2 rigid-body
physics for authority-side bots; replicas still consume network snapshots.

Install
-------

1. Close the game.
2. Keep <game root>\offhangar_user.
3. Delete or move aside <game root>\res_mods\0.8.2.
4. Copy this package's complete 0.8.2 folder into res_mods.

Do not merge individual files. The package must not leave an old
mod_offhangar.pyc behind.

What changed in 1.8.36
----------------------

- LAN snapshots now contain only the fields each recipient uses. The server
  still runs at 30 Hz; physics, collision and damage cadence are unchanged.
- Formation slots keep their own spawn heading instead of all bots snapping to
  one map-wide direction.
- The countdown aiming marker is seeded once and no longer grows when only the
  camera moves.
- A missed narrow ground probe falls through to a real collision search instead
  of treating a baked navigation height as a physical surface.
- The first two native drive canaries record one compact contact/force line.
  This identifies why a body with a valid drive signal still remains at zero
  speed without requiring another special probe package.

Test
----

Start one normal offline or LAN battle. No debug key is required. If bots still
do not move, exit normally and send python.log plus the server log. The useful
rows begin with:

    NATIVE_BOT_PHYSICS drive_diagnostic
    LAN NET
    SERVER PERF

The native bridge automatically rejects an unsupported WorldOfTanks.exe. This
experiment still requires Windows/BigWorld runtime acceptance before it can
replace the stable Python-physics build.
