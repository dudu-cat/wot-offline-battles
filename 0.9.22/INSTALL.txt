World of Tanks 0.9.22.0.1 #1513 LAN/offline package
===================================================

The simplest way to install this package is the launcher. It removes older mod
files, installs this package, sets the server address, starts the LAN server
and starts the game.

To install by hand instead, extract the contents of this folder into the game
root. It contains:

  mods\0.9.22.0.1\org.peng.offline_lan_0922_<version>.wotmod
  mods\configs\offline_lan_0922\config.json
  mods\configs\offline_lan_0922\navgraphs\
  mods\configs\offline_lan_0922\foliage\
  mods\configs\offline_lan_0922\destructibles\

Then start the LAN server on one PC and enter its address in the launcher, or
edit mods\configs\offline_lan_0922\server_endpoint.json. That file holds your
own address and is never shipped in this package.

Play
----

1. Start the client without logging into an online account. On a fresh profile,
   accept the stock EULA once.
2. Select a tank and click Battle!. The client joins the LAN room. The battle
   uses the selected tank and its own health.
3. Every player sees the waiting room. The first player is the room host: the
   host selects a standard map with < and >, then clicks START BATTLE.
4. The server fills both teams to 15 vehicles. Movement and firing unlock when
   the countdown reaches battle.
5. After a team is eliminated the round freezes, and every connected player
   returns to the waiting room after five seconds.

Only standard battles are supported. In this client the internal name of
standard battle is `ctf`; assault and encounter maps are excluded.

Requirements
------------

- The exact Chinese HD client 0.9.22.0.1 #1513.
- The LAN server from the same repository revision, on one PC. It always
  listens on 0.0.0.0:28782 and supports up to 30 players. A single-player round
  also uses it.

Troubleshooting
---------------

- No connection: check the server address, the host firewall and that the
  server window is still open.
- `unsupported compression type`: an older wotmod is still present. Keep only
  the package installed by the launcher.
- The client keeps its own files. Your saved address, account state and
  configuration survive a reinstall.
