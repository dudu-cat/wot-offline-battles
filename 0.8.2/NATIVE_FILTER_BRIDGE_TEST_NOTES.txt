Native vehicle filter input bridge probe 1.8.29
================================================

This diagnostic build leaves production bot movement unchanged. Pressing F6
once during a live battle on the bot-authority client tries four isolated
native pose-seeding paths on one invisible temporary OfflineEntity. Native
drive starts only after the complete x/y/z/yaw pose remains valid after
WGVehiclePhysics2 is attached. Every failed temporary entity is destroyed
before the next candidate is created.

The fourth candidate is a 14.5 KiB x86 Python extension pinned to exactly one
WorldOfTanks.exe. It calls the retail WGVehicleFilter2 Filter::input virtual
method without patching executable code or vtables. It refuses a mismatched
executable in both Python and native code.
